## Project Objectives

- Monitor water level automatically.
- Measure distance using an ultrasonic sensor.
- Display water level percentage on LCD.
- Provide alerts using a buzzer.
- Improve water management and reduce overflow.

## Hardware Components

- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- 16x2 LCD Display
- Buzzer
- Connecting wires
- Breadboard# Arduino-Smart-Water-Level-Monitoring-System
An Arduino-based smart water level monitoring system using an ultrasonic sensor, LCD display and buzzer.
